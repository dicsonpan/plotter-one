# 部署到 RK3399（Armbian）

## 为什么用 RK3399

| | RK3399 | x86 迷你主机 | 树莓派 4 |
|---|---|---|---|
| 常驻功耗 | 3-5 W | 15-25 W | 3-5 W |
| 架构 | ARM64 | x86_64 | ARM64 |
| Node.js 性能 | 足够（CAM 计算是毫秒级） | 富余 | 足够 |
| 成本 | 低 | 中 | 中 |
| 软件生态 | 需确认包可用 | 最好 | 好 |

这个服务的工作量很轻：几何计算、HPGL 指令生成（几十 KB 文本）、
串口按 9600 波特发送。**瓶颈在物理串口，不在 CPU。**
RK3399 的四核 A72 跑这个是杀鸡用牛刀，但功耗只有 x86 的一两个零头。

内存占用实测约 **43MB**（RK3399 / 4GB 板子上跑服务进程的 RSS），
2GB 内存的板子完全够。部署目录 400KB，**零 npm 依赖，不需要 `npm install`**。

## 前置条件

- Armbian（Debian bullseye/bookworm 或 Ubuntu 22.04）已刷好、能联网
- Node.js 18+（安装脚本会自动装）
- 一根 USB 转 RS-232 串口线（**注意必须是 RS-232，不是 USB-TTL**）
  - 常见芯片：CH340、PL2303、FTDI、CP210x
  - ⚠️ USB-TTL（3.3V 电平）**不能**接刻字机的 RS-232（±5V 以上），会烧板子
- 刻字机电源已开

## 一键安装

```bash
git clone <你的仓库> plotter-one
cd plotter-one
sudo bash deploy/install.sh --port 8080
```

脚本会做这些事：
1. 检查并安装 Node.js 18+
2. 拷贝到 `/opt/plotter-one`
3. 创建专用系统用户 `plotter`，加入 `dialout` 组（串口访问权限）
4. 安装 systemd 服务，设开机自启、崩溃自动重启
5. 装 udev 规则，让串口可读写
6. 放行防火墙端口
7. 配 mDNS（可用 `http://armbian.local:8080` 访问，免记 IP）

## 验证安装

```bash
# 服务状态
systemctl status plotter-one

# 实时日志
journalctl -u plotter-one -f

# 看串口设备有没有识别
ls -l /dev/ttyUSB* /dev/ttyACM*
```

浏览器打开 `http://<板子IP>:8080`，应该看到控制台界面。

### 确认串口已自动接回

服务启动时会**自动连接串口**，日志里应该能看到：

```
✓ 已自动连接串口 /dev/ttyACM0 9600
```

没看到也不用手动点「连接设备」——它每 3 秒自动重试一次。
USB 重新插拔导致设备节点变化（`ttyACM0` → `ttyACM1`）也能自动恢复。

```bash
# 确认连接状态（"connected": true 即正常）
curl -s http://localhost:8080/api/state | grep -o '"connected":[a-z]*'
```

### ✅ 首次使用：直接空跑一次

坐标轴方向与版面朝向已在**实机确认**并固化在机型预设里（`machine/hpgl.js`），
界面不再暴露这些开关——它们只用于「机器硬件属性」的排查，
日常使用不需要动，误改会让整版镜像或躺倒。

新机器或换设备时才需要重新确认，步骤：

1. **先空跑**：不放材料，生成一个小图形（比如 50mm 的方框）走一遍
2. 看刀路方向对不对——方向错了图形会**镜像**（左右颠倒），一眼能看出
3. 版面整体躺倒（转了 90°/180°）是**另一回事**，改 `layoutRotate`，不要动轴方向
4. 确认无误再上料

> 实机配置见 README 的「真机验证记录」一节。
> 改预设默认值时，**必须同时检查板子上 `data/config.json` 里的历史值**——
> config 优先级高于预设，旧值会静默覆盖新预设（踩过一次）。

## 串口连接细节

### 找串口

插上线后：

```bash
dmesg | tail -20          # 看是否识别为 ttyUSB0
ls -l /dev/ttyUSB*        # 列出串口
# 查厂商芯片
udevadm info -a -n /dev/ttyUSB0 | grep -E 'idVendor|idProduct'
```

识别到后在网页界面下拉框里选 `/dev/ttyUSB0` 即可。

### 串口参数（力宇机器）

| 参数 | 值 | 说明 |
|------|-----|------|
| 波特率 | 9600 | 力宇标称值 |
| 数据位 | 8 | |
| 停止位 | 1 | |
| 校验 | 无 | |
| 流控 | 无 | 若传输不稳可试 RTS/CTS |

界面默认就是这套参数。

### 排查：设备连不上

```bash
# 1. 权限问题（最常见）
ls -l /dev/ttyUSB0
# 应该是 crw-rw---- 1 root dialout ...
sudo usermod -aG dialout plotter
sudo systemctl restart plotter-one

# 2. ModemManager 抢占串口（Ubuntu/Debian 常有）
systemctl stop ModemManager
systemctl disable ModemManager

# 3. 设备被别的程序占用
sudo fuser -v /dev/ttyUSB0

# 4. 手动测试串口是否通
sudo apt install minicom
sudo minicom -b 9600 -D /dev/ttyUSB0
# 回车看有没有返回字符
```

### RS-232 线缆注意事项

- **长度**：超过 10-15 米容易掉数据。刻字机离板子远时，加 RS-232 延长线或换 USB 延长线
- **交叉还是直通**：RS-232 是交叉（DTE-DCE）。如果不确定，
  拔掉 TX/RX 两根线对调试一次
- **接地**：一定要共地，浮地会导致乱码或丢数据
- **屏蔽**：用带屏蔽层的线，减少电机干扰

## 让局域网更友好

### 固定 IP

编辑 `/etc/network/interfaces`：

```
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
```

### mDNS 免记 IP

安装脚本已配 avahi。直接访问 `http://armbian.local:8080` 即可。
手机装个 mDNS 浏览器（iOS 用 Bonjour，Android 用 Nellymoser）也能解析。

### 手机添加到主屏幕

在手机浏览器里打开控制台 → 分享 → 「添加到主屏幕」。
之后从桌面图标打开，全屏无地址栏，用起来跟 App 一样。

## 开机自启与运维

```bash
systemctl status plotter-one      # 状态
systemctl restart plotter-one     # 重启
journalctl -u plotter-one -f      # 跟踪日志
systemctl restart plotter-one     # 改了 config.json 后
```

配置文件在 `/opt/plotter-one/data/config.json`，改完重启服务生效。

### 升级

```bash
cd plotter-one
sudo systemctl stop plotter-one
sudo rsync -av --exclude node_modules --exclude data/ ./ /opt/plotter-one/
sudo systemctl start plotter-one
```

## 卸载

```bash
sudo bash deploy/uninstall.sh            # 保留配置数据
sudo bash deploy/uninstall.sh --purge    # 彻底清除
```

## 附：技术说明

### 为什么零 npm 依赖

- **串口**用 `stty` + 文件描述符直接读写，不装 `serialport`
  （它带 C++ 扩展，ARM64 上要么没预编译产物，要么现场编译要装交叉工具链）
- **HTTP 服务**用 Node 内置 `node:http`
- **WebSocket**自己实现（RFC 6455 服务端最小实现约 100 行，见 `server/api/httpKit.js`）
- **前端**免构建，直接用原生 JS，部署即拷贝文件

好处：RK3399 上 `npm install` 都不需要，升级就是覆盖文件，不会因为
某个包版本变动而构建失败。

```
│   │   ├── transport.js      串口/TCP/虚拟传输层
│   │   └── jobEngine.js      任务引擎（流式下发、暂停续传）
│   ├── cam/
│   │   ├── toolpath.js       刀路编译（清理、方向、排序）
│   │   └── textToPath.js     内置单线字体

```

### 精度说明

已验证：生成 HPGL → 反向解析回来，长度误差 **0.01%**、包围盒误差 **0.0003%**。
在 800mm 幅面上是 0.08mm，远小于力宇标称的重复精度 0.127mm。

跑自检：

```bash
node server/selftest.js
```
