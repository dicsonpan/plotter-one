# 设计工作流：用什么做设计，怎么做

> 这份文档回答两件事：
> 1. 图形到底该用什么软件做
> 2. 一个从设计到刻完的完整案例，照着做就行

---

## 零、先对机器：SC631-AU 参数速查

本项目按你这台机器设定。**参数以机身铭牌为准**，这里列出来是为了让你核对。

| 项目 | 本机设定 | 厂商资料的其他说法 |
|------|---------|------------------|
| 最大刻绘宽度 | **600mm**（保守） | 615mm / 630mm |
| 最大进纸宽度 | 710mm | 710mm（一致） |
| 分辨率 | 0.0254mm/step（1000 步/英寸） | 一致 |
| 重复精度 | 0.127mm | 一致 |
| 最大切割速度 | 800mm/s | 一致 |
| 刀压 | 10–500g | 1–500g / 10–500g |
| 指令格式 | HP-GL / DM-PL | 一致 |
| 接口 | USB 2.0 + 串口 | 一致 |
| 缓存 | 1GB 循环 | 一致 |

### 为什么刻绘宽度按 600 而不是 630

不同资料对 SC631-AU 的刻绘宽度给了 600 / 615 / 630 三个值。本项目**默认取最小值 600mm**。

原因很直接：幅面设小只是排版受限，设大了是**刀走出材料、撞机甚至断刀**。
少刻 30mm 的代价远小于撞机。

**如果你确认机身铭牌写的是 630mm**，在界面「机器型号」下拉框里改选
「力宇 SC631E / SC631-AU（630mm）」即可。

### 巡边功能（如果是带巡边的版本）

SC631-AU 系列有「自动巡边裁切」版本：机器沿材料边缘走一圈，自动裁断边料。
资料标称最大巡边宽度 **560mm**。

> ⚠️ 巡边是**机器端的功能**，通过面板按键触发，不走 HPGL 指令，
> 所以本服务不参与、也无法控制它。裁切时先在面板上设好巡边宽度，
> 图形设计时注意别超出 560mm。

判断是否带巡边：面板上有没有「巡边」相关按键，或机身是否带侧向裁纸机构。

## 一、先说结论

**设计不要在浏览器里做。** 用你顺手的那款矢量软件，做好了导成 DXF 传过来。

浏览器里做设计是反模式：专业矢量软件有节点编辑、布尔运算、路径查找这些
打磨了二十年的能力，浏览器里重写一遍，既不完整也不好用。服务端这边
（也就是这个项目）只负责**输出**——连机器、算刀路、下发、监控、回位。

这跟 LightBurn 那些软件的思路一样：设计是一回事，输出设备控制是另一回事，
后者才需要常驻在机器旁边的板子上。

## 二、设计软件选型

按你现在的实际情况排，从最推荐往下：

### 首选：Adobe Illustrator

刻字机行业的事实标准，理由很实在：

- **文泰能被替代**。Illustrator 的 `路径查找`（Pathfinder）能做合并/取差/分割，
  文泰的「图形运算」就是这回事。装一个永久授权版（学生优惠或 Creative Cloud），
  一次性投入，长期省事。
- **刻字行业的模板、字库、刀库都能用**。你现有的资源不用推倒重来。
- AI 的 `效果 → 路径` 一键把文字/描边转成轮廓，这对刻字机至关重要（见下文）。

### 次选：Inkscape（免费）

如果不想订阅，用这个。能力上覆盖了实际需要的 80%：

| 需求 | Inkscape 怎么做 |
|------|----------------|
| 合并/取差 | 路径 → 交集 / 差集 / 并集 |
| 文字转轮廓 | 路径 → 对象转路径 |
| 偏移（刀口补偿） | 路径 → 偏移路径（实验特性，可能需开启） |
| 简化节点 | 路径 → 简化 |

代价：没有「效果 → 路径」这种一键操作，要用菜单一项项点；中文排版比 AI 弱。

### 够用：Figma / 浏览器工具

Figma 画简单图形（几行字、一个图标）够用，导出 SVG 直接能用。
适合"临时改个字"这类小活，不适合正式出图。

### 完全够用：AI（画图 AI）

把创意直接生成矢量图，省掉手工绘制。但注意：**必须转曲/转路径后再用**，
否则发丝级细节会让刻字机变成砂纸打磨机。

### 不推荐

- **AutoCAD / SolidWorks**：是 3D/CAD 工具，出 2D 矢量要走一堆设置。
- **直接在浏览器里画**：见开头。

## 三、导出设置：这一步决定成败

> ⚠️ **90% 的「刻废了」问题出在导出设置上，不是机器上。**

### 通用规则

| 项目 | 设置 | 原因 |
|------|------|------|
| 格式 | **DXF**（首选）或 PLT | PLT 已经是 HPGL 了，通用性差；DXF 保留完整几何 |
| 单位 | **毫米（mm）** | 导入时若单位是英寸，本系统按 mm 读，会放大 25.4 倍 |
| 版本 | AutoCAD 2000 或更高 ASCII | 老版本 DXF 最稳，R12/R14 兼容性最好 |
| 二进制 DXF | **不要** | 本系统只解析 ASCII DXF |
| 文字 | **必须转曲（轮廓化）** | 见下 |

### 关键：文字一定要转轮廓

**导出的 DXF 里如果还有 `TEXT` 实体，本系统会把它当未知元素忽略——结果就是刻的时候那行字凭空消失。**

在 Illustrator 里：全选 → `效果/效果` → `扩展外观`（Expand Appearance）
或 `对象 → 路径 → 轮廓描边`。

在 Inkscape 里：全选 → `路径` → `对象转路径`（Object to Path）。

转完再导 DXF，就不会有这个问题了。

### 单线字：刻小字的必备技巧

刻字机是**跟着刀尖走**的。一行 10mm 高的字，笔画宽度只有 0.5mm，
刀尖直径通常 1-2mm，会直接**犁过去**，刻出来是一团糊。

两个办法：

**办法 A：用单线字体（推荐）**
字形本身就是一根线，刀走过即成。UcanSign 内置了单线字体，
Illustrator 里也有大量免费单线字体（如「文泉驿单线体」等）。
特点：字形细、笔画单一、刀宽多少都能刻。

**办法 B：普通字体 + 加大刀宽**
如果只能用黑体这类粗字体，把刀换成最细的（0.4mm 以下），
并把字放大到 60mm 以上。这条路精度要求高，不推荐批量作业。

### 刀口补偿

刀尖宽度会让实际切口比路径**宽出刀宽那么多**。比如刻两条间距 3mm 的线，
刀宽 1mm，实际切口会是 4mm，两条线粘连。

补偿做法：在设计软件里把要刻的图形**向外偏移刀宽的一半**。
Inkscape 用 `路径 → 偏移路径`；Illustrator 用 `对象 → 路径 → 偏移路径`（Object to Path），
偏移量填刀宽的一半，勾选「圆角端点」。

本系统目前不自动做补偿（不同材料收缩率不一样，自动补偿反而容易出错），
建议设计时手工补偿，或者切完第一个样品后按实际误差调整。

## 四、典型案例：做一块亚克力门牌

从零到刻完，按顺序做。

### 场景

一块 300×200mm 的 3mm 亚克力，刻一块门牌：
「创智实验室」主标题 + 一行小字 + 一个圆形 Logo 轮廓 + 外边框。

### 第 1 步：在设计软件里做完

以 Illustrator 为例（Inkscape 操作类���）：

1. 新建文档，**单位设成毫米**，画板 300×200mm
2. 外边框：用矩形工具画 280×180mm 的框，中心对齐画板
3. Logo：从网上找一个矢量 logo（SVG/AI 格式）拖进来，
   用选择工具 `窗口 → 外观 → 外观面板` 里的"外观 → 扩展外观"转轮廓
4. 主标题「创智实验室」：
   - 字体用**单线字体**（如「文泉驿正楷单线体」）
   - 字高设 **45mm**（门牌要够远看清）
   - 旋转 0°，水平居中
   - `效果 → 扩展外观` 转轮廓
5. 副标题「SPARKMINDS LAB · GUANGZHOU」：
   - 同一套单线字体，字高 **10mm**
   - 放在主标题下方，间距 8mm
   - 转轮廓
6. **全部选中** → 检查：右侧图层面板里不能有 `文字` 图层

### 第 2 步：导出 DXF

- `文件 → 导出 → 导出为…` 或 `另存为` 选 `Illustrator (.ai)`
- 然后 `文件 → 导出 → 导出为…` → 选 **DXF**
- 弹出选项框时：
  - 范围：**整个文档**（不要选"选中对象"，容易漏）
  - 单位：**毫米**
  - 格式：**ASCII DXF**，版本 **AutoCAD 2000**
  - 勾选 **只导出路径**（对应 Inkscape 的"仅路径"）
- 保存为 `门牌.dxf`

### 第 3 步：传到控制台

1. 浏览器打开 `http://<板子IP>:8080`
2. 左栏「导入文件」→ 选择 `门牌.dxf`
3. 画布上出现图形，检查：
   - **原点在左下角**（红点），图形应该整体在这个点右上方
   - 图形有没有超出白色材料框
   - 图形长宽对不对

> 如果图形在原点左下方，说明设计时坐标是负的。在设计软件里整体右移+上移，
> 或者用本系统的图形工具重新定位。

### 第 4 步：调参数

1. 右栏「材料预设」选 **3mm 亚克力**（预设速度 12mm/s、刀压 420g）
2. 但第一次别用预设！先看刀压旋钮在机身上的当前值，
   把界面上的刀压滑块**调到和机身旋钮一致**
   （3mm 亚克力建议机身调 350-420g）
3. 速度先调到 **10mm/s** 试刻
4. 走刀方向保持**逆时针**（切口无毛边）

### 第 5 步：空跑检查（重要！）

**不放材料**，直接点「预览刀路」：

- 看刀路动画，确认：
  - 走刀顺序合理，没有大跨度来回跑
  - 每个字都是完整一笔，没有断在半路
  - 边框是闭合的（回到起点）
- 看「刀路概览」：
  - 总长度：这块牌子约 3000-5000mm
  - 预计耗时：按 12mm/s 算，大概 4-7 分钟

### 第 6 步：试刻定位

1. 放一块**废料**亚克力在机器上
2. 校准原点：让刀尖对准废料左下角（不落下）
3. 机身面板按「回原点/校准」
4. 点「生成指令」→ 界面会显示指令预览
5. 点「开始刻绘」

### 第 7 步：看第一刀

刻第一刀时**在旁边盯着**，重点看：

- 刀有没有落下去（听到机器的切割声）
- 刻出来的线粗细是否均匀
- 走到哪里的深浅是否一致

有异常立刻按「急停」。

### 第 8 步：调参定型

第一块试刻后：

- **刻不断/太浅** → 刀压 +20g，或速度 -2mm/s
- **刻太深/有毛边** → 刀压 -20g，或速度 +3mm/s
- **整体偏细** → 换细刀（0.4mm 以下）
- **字口糊了** → 字高加大到 50mm 以上，或换更细的单线字体

调好后把参数存进材料的自定义预设，下次直接用。

## 五、常见问题

**Q：导入后什么都不显示？**
A：先看坐标。刻字机的原点在材料左下角，如果设计文件坐标是负的，
图形会跑到材料区外面。用 `Ctrl+A` 检查有没有负坐标。

**Q：字刻出来是方的（缺字）？**
A：导出时没转轮廓。DXF 里的 `TEXT` 实体本系统不解析。
回到设计软件做「扩展外观/对象转路径」再导。

**Q：整版偏了 1-2mm？**
A：原点没校准。刻字机开机后必须先「回原点」确定物理零点，
手动把滑块推到边缘再回原点，让坐标系和实际对齐。

**Q：整版偏了 1.6%（比如 800mm 幅面末端偏 13mm）？**
A：这不是设置问题，是分辨率。本系统对力宇机型按 **1000 步/英寸** 计算
（力宇标称 0.0254mm/step）。如果你的机器实际是别的分辨率，
在 `server/machine/hpgl.js` 的 `MACHINE_PRESETS` 里改 `stepsPerInch`。
换算：1016 = HPGL 标准，4060 = 部分力宇 4 轴机。

**Q：刻到一半停了？**
A：看「运行日志」。最常见是串口接触不良（松了或线太长）。
RS-232 线超过 10 米容易掉数据；USB 转串口线质量差的也容易断。
换短一点的线或换一根质量好的。

**Q：能不能一次刻很多块？**
A：能，但要在设计软件里排好版（本系统不做自动排样）。
导出前把图形阵列排好，一次输出。力宇标称有 1MB 循环缓存，
指令在 200KB 以内通常没问题。

## 六、一句话总结

> **设计用 Illustrator（单线字体 + 转轮廓），导出 ASCII DXF / mm，
> 传到控制台，先空跑再试刻，第一刀在旁边盯着。**
