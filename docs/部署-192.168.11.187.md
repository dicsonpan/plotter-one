### 单元关键片段（/etc/systemd/system/plotter-one.service）

```ini
[Service]
User=sparkminds
Group=sparkminds
WorkingDirectory=/opt/plotter-one
ExecStart=/opt/node20/bin/node server/index.js --port 80 --host 0.0.0.0
Restart=always
RestartSec=3
AmbientCapabilities=CAP_NET_BIND_SERVICE
CapabilityBoundingSet=CAP_NET_BIND_SERVICE
```


## 踩过的坑

### 1. SSH 偶发 Permission denied（成功一次后第二次被拒）
短时多次尝试（含错误密码 root/P@ssw0rd 试 165 那台）可能触发 sshd 限流。重试一次或等几十秒即可，不是凭据错。

### 2. 端口从 8080 改 80 必须加 capability
sparkminds 是非 root，直接 `--port 80` 会 `EACCES: permission denied 0.0.0.0:80`。
在 systemd 单元加 `AmbientCapabilities=CAP_NET_BIND_SERVICE` 解决（不要改成 root 跑，串口权限反而更麻烦）。
